In this lab, I experiment with viewing interface information and filtering cli output.

cli

show interfaces terse ge-0/0/6
show interfaces brief ge-0/0/1
show interfaces ge-0/0/2
show interfaces ge-0/0/3 detail

show interfaces terse
show interfaces terse | match ge
show interfaces terse ge*
show interfaces terse ge* | match down
show interfaces terse ge* | match physical
show interfaces terse ge* | match "physical|flapped"
show interfaces terse ge-0/0/1 | except fe80
show interfaces ge* | match physical | except down
show interfaces ge* | match physical | count
show interfaces ge00/0/2 | find logical
